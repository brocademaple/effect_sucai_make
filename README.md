# 特效素材制作器

一个纯前端的图片背景去除 / 抠图工具，用于快速制作抖音等平台的特效素材图片。上传任意图片，通过多种抠图工具去除背景，导出干净的透明底素材。

## 功能特性

- **多种抠图方式** — 矩形选区、自由套索、取色去背景、魔棒、自动去背景
- **手动精修** — 橡皮擦擦除多余区域，恢复画笔找回误删内容
- **参数可调** — 容差值、羽化边缘、画笔大小均可实时调节
- **实时预览** — 棋盘格 / 白 / 黑 / 绿色背景切换预览效果
- **多格式导出** — PNG（透明背景）、JPG（白底）、WebP
- **自动裁剪** — 导出时自动裁剪到内容区域，去除多余空白
- **撤销重做** — 支持最多 30 步历史记录
- **键盘快捷键** — 全套快捷键提升操作效率
- **零依赖** — 纯 HTML + CSS + JavaScript，无需安装任何第三方库

## 快速开始

```bash

git clone <repo-url>
cd effect_sucai_make

# 启动服务
node server.js

# 浏览器访问
# http://localhost:3000
```

也可以直接用浏览器打开 `index.html` 文件使用（无需启动服务器）。

## 工具说明

| 工具 | 快捷键 | 用法 |
|------|--------|------|
| 矩形选区 | `V` | 拖拽框选区域，按 `Delete` 去除选区内背景 |
| 自由套索 | `L` | 手绘闭合选区，保留选区内、去除选区外 |
| 取色去背景 | `C` | 点击背景色，全图去除相似颜色 |
| 魔棒工具 | `W` | 点击某处，从该点 flood-fill 去除连通的相似色块 |
| 自动去背景 | `A` | 一键自动检测边缘背景色并去除 |
| 橡皮擦 | `E` | 拖拽擦除不需要的区域 |
| 恢复画笔 | `R` | 拖拽恢复被误擦的区域 |
| 移动画布 | `H` | 拖拽平移画布视图 |

## 使用流程

1. **上传图片** — 点击"上传图片"按钮或直接拖拽图片到页面
2. **选择工具** — 根据图片背景类型选择合适的抠图工具
   - 纯色背景 → 推荐「取色去背景」或「自动去背景」
   - 复杂背景 → 先用「矩形选区」或「套索」粗选，再用「橡皮擦」精修
3. **调节参数** — 通过右侧面板调整容差值和羽化边缘
4. **精修细节** — 用橡皮擦去除残留，用恢复画笔找回误删部分
5. **预览确认** — 切换预览背景色检查抠图效果
6. **导出素材** — 选择格式后点击"导出图片"下载

## 导出格式

| 格式 | 特点 | 推荐场景 |
|------|------|----------|
| PNG | 支持透明背景，无损 | 特效素材首选 |
| JPG | 白色背景填充，体积小 | 不需要透明底的场景 |
| WebP | 支持透明背景，体积更小 | 兼顾质量和体积 |

## 技术实现

- **Canvas 像素操作** — 直接操作 ImageData 实现颜色比对和 alpha 通道修改
- **Flood-Fill 算法** — 魔棒和自动去背景使用 BFS 连通区域填充
- **边缘羽化** — 基于距离的 alpha 渐变，使抠图边缘更自然
- **Alpha Mask 架构** — 独立的遮罩层记录透明度，原图数据不被修改，支持无损撤销恢复
